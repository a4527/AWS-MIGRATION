- deregistration delay는 rolling 배포 시간을 줄이지 않았다(11-20·11-23 190·191초 → 255초). 이전 배포의 세부 이벤트가 없어 차이의 원인은 미확인이다.
- `arch01_measure.py`의 ECS 이벤트 필터가 KST 문자열과 UTC를 비교해 이전 이벤트가 섞여 나와 시각 비교로 고쳤다. k6 요약에 업로드 건수·송수신 바이트를 추가했다(부하 내용은 같음).

## 개인 계정 철거 마무리

- 사용자가 개인 계정 백업 bucket을 콘솔에서 비우고 지웠다. MFA 세션이 만료돼 API 대신 공개 엔드포인트로 확인했다: `NoSuchBucket`.
- `terraform/environments/backup`(코드·로컬 state·tfvars·`.terraform`)을 지웠다. 문서의 디렉터리 트리를 고쳤다.
- 개인 계정 IAM user `fileshare-backup-admin`(access key 있음)과 role `fileshare-backup-bucket-admin`은 비용이 없어 남겨 두기로 했다(사용자 결정). 로컬 CLI 프로필(`personal`, `personal-backup`, `personal-backup-tf`)도 그대로다.
